# 🎙️ English Buddy — Full Build Plan
> AI-powered spoken English coach for students in tier 2/3 Indian towns
> Built for NGO deployment | Target: ~300 students | Goal: professional-standard spoken English

---

## 1. Project Overview

**What it is:** A voice-first web app (PWA) where students have real spoken conversations with an AI coach. The AI responds naturally, then gives targeted feedback on grammar, vocabulary, fluency, and pronunciation after each exchange.

**Who it's for:** Students from tier 2/3 towns in India, aiming for professional English fluency — job interviews, workplace communication, customer-facing roles.

**How it works:**
1. Student picks a scenario (free talk / interview / workplace)
2. Taps mic → speaks → AI listens
3. AI responds in natural spoken English
4. Feedback panel shows what was good, what to fix, and a corrected version
5. Repeat until session ends

## 2. Tech Stack

| Layer | Tool | Cost | Notes |
|---|---|---|---|
| Framework | React + Vite | Free | Fast dev, great PWA support |
| Styling | Tailwind CSS | Free | Mobile-first by default |
| Speech Input | Web Speech API | Free | Built into Chrome (Android + Desktop) |
| Speech Output | Web Speech Synthesis | Free | Built into all browsers |
| AI Brain | Claude API (Haiku) | ~₹100/student/month | Smart enough for this use case |
| Hosting | Vercel | Free tier | One-click deploy, global CDN |
| Storage (now) | localStorage | Free | No backend needed to start |
| Storage (later) | Supabase | Free tier | Postgres + Auth when ready |

**Why PWA over native Android:**
- One codebase for web + Android home screen install
- No Play Store approval process
- Students on Chrome Android get full mic access
- Easy to update without app store submissions

## 5. The Prompt Architecture

Claude does two things per turn: **converse** and **evaluate**.

> **Implementation note:** The plan originally described a two-block text format
> (`RESPONSE: [text]` + `FEEDBACK: {json}`). We use pure JSON instead — more
> reliable to parse, less likely to break on edge cases.

```
SYSTEM PROMPT (prompt-cached → sent once, charged at 10% on repeat calls)
├── Role: You are Maya, a friendly English coach...
├── Context: Students from tier 2/3 Indian towns...
└── Response format: Always reply as valid JSON...

CLAUDE OUTPUT (pure JSON)
{
  "reply": "That's great! Tell me more about your experience...",
  "feedback": {
    "grammar": { "issue": "...", "correction": "...", "tip": "..." },
    "vocabulary": { "suggestion": "...", "example": "..." },
    "fluency_score": 7,
    "filler_words": ["um", "basically"],
    "overall": "Good effort! Your main area to improve is..."
  }
}
```

The app speaks only `reply` aloud. The `feedback` object goes to the FeedbackCard.

## 6. Scenarios — Detail

### Free Conversation
- AI introduces a topic (current events, hobbies, aspirations)
- Asks follow-up questions based on what student says
- Good for building general fluency and confidence

### Job Interview Simulation
- AI plays an interviewer at a company relevant to student's goal
- Standard questions: Tell me about yourself / Why do you want this role / Strengths & weaknesses
- After each answer: feedback on structure, filler words, professional vocabulary

### Workplace Scenarios
Specific scripted scenes:
1. **Team standup** — report your work to the team
2. **Customer call** — handle a complaint professionally
3. **Presenting to your manager** — pitch an idea clearly
4. **Asking for help** — frame a question professionally

## 8. Key Technical Decisions & Rationale

**Why Web Speech API over Whisper?**
Web Speech API is free and runs in the browser — no audio uploads, no server cost, works instantly. Whisper would add ~$0.006/minute in costs and require a backend. For this use case, browser speech recognition is sufficient.

**Why Claude Haiku over Sonnet?**
At the fluency level of the target students, Haiku provides feedback that's indistinguishable in quality from Sonnet, at 1/4 the cost. Switch to Sonnet if advanced students need more nuanced feedback.

**Why pure JSON response over two-block format?**
Reliable. No string splitting, no regex, no format drift. Claude is instructed to return valid JSON and parsing failures are caught cleanly.

**Why PWA over React Native?**
No Play Store submissions, no native build toolchain, no separate codebase. Chrome on Android supports full mic access and home screen install.

**Why localStorage before Supabase?**
Gets a working product deployed in days instead of weeks. Add cloud sync when there's a reason to (multiple devices, admin reporting).
